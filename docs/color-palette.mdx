# Colors

The colours come from the [`@gls-nxt/design-tokens`](https://github.com/gls-nxt/design-tokens) package. For more in-depth documentation, see the [Unity Design System](https://www.figma.com/design/rUvwRrvXRta7egY4ju7JQm/Unity-Design-System?m=auto&node-id=708-14768&t=MAVfvE0QDak2RIh8-1) in Figma.

Components use the semantic colours only. The base colours are the raw values the semantic colours point to.

### Ramps

Each light ramp sits next to its dark ramp. Each swatch lists the colours from its pair that pass [WCAG 2.2 AA](https://www.w3.org/WAI/WCAG22/Understanding/contrast-minimum.html) contrast (≥ 4.5:1 for normal text). The number is the contrast ratio.

## Semantic colours

The semantic colours change with the colour mode. They follow the operating system setting, or `data-theme="light"` / `data-theme="dark"` on `<html>`. The swatches show the active mode.
