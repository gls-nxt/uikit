# Color Palette

Our Color Palette is the base of our design system. It is used to create a consistent look and feel across our products. For more in-depth documentation, you can check out the [Unity Design System](https://www.figma.com/design/rUvwRrvXRta7egY4ju7JQm/Unity-Design-System?m=auto&node-id=708-14768&t=MAVfvE0QDak2RIh8-1).

## Color Palette

Each color swatch shows which colors from its group pass [WCAG 2.1 AA](https://www.w3.org/WAI/WCAG21/Understanding/contrast-minimum.html) contrast requirements (≥ 4.5:1 for normal text). The number next to each name is the contrast ratio.

In this palette we use a numeric value to represent the shade. For more in-depth documentation, you can check out the Primitive Color section in [Figma](https://www.figma.com/design/rUvwRrvXRta7egY4ju7JQm/Unity-Design-System?m=auto&node-id=708-14776&t=MAVfvE0QDak2RIh8-1).
