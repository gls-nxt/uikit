## GLS-UIKit 🎨

#### The global design system for the GLS ecosystem.

**@gls-nxt/uikit** is a collection of reusable components, styles, and utilities that are used across the GLS web ecosystem. This library is built with React and module CSS using the Radix UI primitives and is designed to be used in any React application.

With **@gls-nxt/uikit** library, you can build consistent, accessible, and performant user interfaces across the GLS web ecosystem.

## Installation

With pnpm

```bash
pnpm install @gls-nxt/uikit
```

### Goals

- Create a component that supports all the required browser versions.
- **Consistency**: Ensure that all components and styles are consistent across the GLS web ecosystem.
- **Performance**: Ensure that all components are optimized for performance.
