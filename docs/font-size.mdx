# FontSize

The tokens come from the [`@gls-nxt/design-tokens`](https://github.com/gls-nxt/design-tokens) package.

## Text styles

Components use the text styles. Each style has a `-font-size`, `-line-height` and, for headings and body, `-letter-spacing` token. The values change with `data-viewport="mobile"` or `data-viewport="locker"` on `<html>`; the default is desktop.
