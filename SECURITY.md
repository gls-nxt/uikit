# Security policy

## Supported versions

Only the latest published version of `@gls-nxt/uikit` receives fixes.

## Reporting a vulnerability

Do not open a public issue for a security problem.

Use GitHub's private vulnerability reporting instead: open the **Security** tab of this repository and choose **Report a vulnerability**. Only the maintainers see the report until a fix is published.

We aim to acknowledge a report within five working days.
